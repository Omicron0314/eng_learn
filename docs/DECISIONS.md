## 领域规则与学习调度

| ID | 决策内容 | 原因与约束 |
| --- | --- | --- |
| D13 | 保留 FSRS 记忆评估、确定性 `KnownSet`、覆盖率分析与 7 天对照实验口径 | 核心学习算法语义不变，由纯 Rust 重新实现并通过 64 组跨语言向量校验（向量集见 `spikes/r00/fsrs-vectors.json`） |
| D17 | 词书正规化为独立实体（`word_books` + `book_entries`），卡片按词元跨书去重；删书时有复习历史的卡片显式归档（`archived_at`） | 支持多词书共享同一词卡；区分“用户手动暂停”与“删书历史归档”，防止普通开关误恢复归档卡 |
| D18 | 新增真实 `audio_complete` 事件、阅读/播放会话去重与 13×7 热力图统计口径 | 热力图要求可靠的学习活动记录，不能用“点击播放”推测“听完” |
| D39 | 设置数值范围由领域层统一校验；播放速度集合统一支持 `0.75 / 0.9 / 1.0 / 1.1 / 1.25`（兼容旧 `1.5 / 2.0`） | 保证学习设置与设备偏好校验一致 |
| D49 | 复习卡首次翻面且释义为空时，按例句/词面自动请求一次语境释义并持久化（`generated`），追加 `card_gloss` 事件 | 失败不阻塞翻面或评分；卡片 revision 随释义回填递增，防止并发评分覆盖 |
| D53 | **学习步骤对齐 Anki 26.09.3 默认规则**：learn `1m/10m`、relearn `10m`、毕业 `1d/4d`、learn-ahead `20m`；主队列按 `MixWithReviews` 交错 | Hard 停在当前步（首步 `5.5m`），Good 推进并在末步毕业，Easy 直接毕业到 `4d`；主队列为空时 20 分钟内的学习卡直接入队允许提前评分 |
| D57 | **复习与重学间隔采用 Anki 26.09.3 非 FSRS ease 调度**（初始 ease `2.5`），FSRS 仅用于可提取率与统计展示 | 与用户本机 Anki 行为保持一致；新增 `cards.ease_factor`（旧卡默认 `2500`） |

## 存储、导入、音频与数据迁移

| ID | 决策内容 | 原因与约束 |
| --- | --- | --- |
| D07 | 独立 SQLite 存储层；领域层零 IO，UI 仅通过应用服务收发命令与查询 | 业务写入与 `events`、`command_receipts` 同事务提交 |
| D10 | 桌面密钥优先使用系统凭据存储（`SecretStore`），不可用时明确回退至会话内存并在界面展示真实来源 | 替代旧版 SQLite 明文存储；绝不将密钥写入事件、日志或备份包 |
| D26 | 文章生成任务持久化不含密钥的请求快照；通过条件更新防止重复领取，取消或重启后拒收迟到结果且不自动重试付费调用 | 避免后台重复计费；单数据目录由单桌面进程独占 |
| D30 | Linux 本机免费朗读探测并调用 `espeak-ng` 合成 WAV，交由统一原生播放器输出 | 不消耗远程 TTS 字符额度；自然播放结束由播放器回调触发持久化 |
| D32 | 学习设置（随 profile）与设备偏好（主题、语速、口音、自动朗读，随 device）分离存储 | 多窗口主题隔离，设备偏好改动即时生效 |
| D33 | 旧 Web 数据库迁入采用只读 SQLite 事务固定 WAL 一致性快照，逐表转换并在临时目录校验通过后以无覆盖重命名发布 | 不复制含明文密钥的临时整库；缺失的历史字段保留 `null` 或 `legacy` 标记，不伪造数据 |
| D35 | v2/v3 逻辑备份、迁入指纹与命令哈希统一使用对象键排序的稳定 JSON；v3 支持可选打包经 SHA-256 校验的音频缓存 | 保证跨构建哈希稳定；损坏备份在预检阶段整包拒绝 |
| D38 | CSV/TXT 采用流式按记录读取并同步计算 SHA-256，单条原始记录上限 1 MiB，不设任意文件总大小硬限制 | 保留跨块 UTF-8、CRLF 与多行引号的准确行号 |
| D59 | **单词发音作为一等资产独立存储**（`word_audio` 表 + `<sha256>.mp3` 内容寻址 blob，`lexemes.ipa_uk/ipa_us`） | 与文章整篇音频、额度预留及播放会话完全解耦；复习点播走独立音频 sink，不计入文章完成或远程 TTS 额度 |
| D60 | 维护工具 `cijian-fill` 统一通过有道接口补齐英/美发音与音标，运行期桌面应用绝不直接请求该非公开接口 | 取不到音标时留空，绝不由模型猜测或编造 IPA；调用点收敛在 `crates/cijian-providers/src/youdao.rs` |
| D61 | 词包 `.cijianpack` 以“清单 + 六列词表 + 双口音音频 blob”自包含分发，导入时先全量校验 SHA-256 与容器再落盘写库 | 损坏词包整包拒绝，不留半本词书；跨词书共享相同词元音频自动去重 |

## 界面交互关键约定

| ID | 决策内容 | 原因与约束 |
| --- | --- | --- |
| D44 | 桌面端采用 48dp 应用内自绘标题栏（Linux 提供最小化、全屏、关闭三键，macOS/Windows 复用平台原生控件） | 解决平铺窗口管理器（如 niri）下无原生标题栏按钮的问题；关闭窗口时复用脏草稿与阅读位置保护 |
| D62 | 后台轮询（生成状态、播放进度）与本地即时控制（点播单词、音频控制、设备偏好切换）标记为 `Command::is_quiet()` | 不置全局 `loading`、不弹忙碌提示条、不打断用户翻面或评分；前台慢请求延迟 400ms 再显示忙碌提示 |
| D63 | 设置 AI 页常驻展示 LLM 与 TTS 双卡片独立草稿，点击“保存并生效”先统一校验再依次提交两条 `SaveProvider` | 取代容易误操作的“编辑 LLM / 编辑 TTS”切换标签；单卡清除密钥互不影响，底部操作栏固定不随表单滚动 |
