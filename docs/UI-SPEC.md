# 页面与交互规范

以 [cijian-m3.html](cijian-m3.html) **执行 JavaScript 后的画面**为准。`overview` 是设计说明；顶部目录、缩放器、画板标题和静态示例链接不属于产品。状态与规则由 [SPEC-CORE](SPEC-CORE.md) 定义，视觉由 [DESIGN-SYSTEM](DESIGN-SYSTEM.md) 定义。

## 导航与布局

主入口按「今日、复习、文章、词库、生词箱、统计」排列。桌面 96dp 导航轨，设置固定底部；文章详情高亮文章。紧凑布局采用六项底部导航，设置在顶部；412dp 保留设计顺序，360dp 仍需标签可读、命中区不重叠，若出现尺寸冲突先记录设计补充，不静默删入口。专注复习可隐藏底栏。

路由是共享应用状态：`Today / Review / Articles / Article(id, mode) / Library(filter) / Inbox / Stats / Settings(section)`，不是对 Next 路径的依赖。桌面用返回栈，浏览器适配 URL／历史；返回恢复筛选、滚动和草稿。未知文章呈现不可用状态。

规划断点：compact <600dp；medium 600–839dp；expanded ≥840dp。三栏布局需 ≥1200dp，否则合并辅助栏或按需打开 sheet。断点为补充默认，真实字体放大后以内容可用为准。

## 今日

日期／问候基于本地显示时间；队列和“今日”统计用学习日规则。主卡显示剩余总数及学习中、待复习、新词数量，按钮进入相同快照对应的队列。队列为零区分“本日任务完成”“暂无词卡”“等待学习步骤到期”，给出文章、导入或下次到期的合适入口。

我的词书跳转词库并带 bookId。侧栏显示待处理生词摘要、本周活跃与新学／复习、近 13 周热力图；点击／聚焦热力格显示日期和活动数。手机首页按画板保留复习、生词入口和紧凑热力图，词书管理仍可从词库导航进入。

## 复习

正面只显示提示、单词与所属词书；点击卡片／“显示答案”或 Space 翻面。背面显示释义、例句和来源标签；没有释义时发起一次按需生成，失败可重试或稍后编辑，不禁止评分。

四档为重来／困难／记得／轻松，分别显示 FSRS 算出的间隔，不复制画板的 1 分钟、8 分钟、3 天、9 天。翻面前评分禁用，提交中锁住四个按钮；成功后换卡并更新计数，失败保留当前卡与答案。键盘 1–4 仅在背面、无输入焦点、无 modal 时生效。退出不撤销已保存评分；再次进入重新取有效队列。

## 文章工作区与详情

工作区左栏生成器：难度、覆盖率说明、自动轮换／短故事／对话／独白；右栏今天文章，显示体裁、档位、实际覆盖率、字数、未读／已读及最新阅读反馈。补充历史列表入口与日期筛选以支持已有内容长期使用，沿用同一列表样式。

生成中展示选词、写作、校验阶段与不确定进度；禁止重复提交。失败保留配置并提供重试／服务设置。没有候选词时引导复习或导入；已到期候选存在时不强制先评分。生成成功进入详情并可返回列表。超过重试仍偏难可保留文章，但明显显示实际覆盖率与提示。

阅读正文按原文排版，词间空白与标点不变。点词／键盘选词显示完整所在句、lemma、可用的音标／词性／发音、语境释义、来源及缓存状态；数据缺失显示缺失而不编造。expanded 布局侧栏挤出正文空间，不盖住当前句；紧凑布局用带遮罩 bottom sheet，可关闭并还原焦点。快速切词时只显示最新选择的结果。

“认识”记录标记；“不认识”按模式进入生词箱或建卡；“加入复习”显式建卡。按钮回显已加入／已存在及是否暂停，不假装重复创建。点词模式说明带设置跳转。正文末尾有“读完了”和三档反馈；完成与反馈是不同动作，已读标识可持续。

不自然反馈弹窗列句子供多选，备注最多 200 个 Unicode 字符；至少选择一句或填写非空备注。提交中禁重复；成功关闭并提示，失败保留选择和备注。

## 听力与播放器

先听模式默认收起原文，“显示原文”切到阅读。缓存音频支持播放／暂停、进度、后退 5 秒、五档倍速 0.75 / 0.9 / 1.0 / 1.1 / 1.25，记住上次速度。阅读模式悬浮工具栏留出正文底部空间，不遮挡反馈按钮。

尚无音频时必须由用户点击生成；生成中不能重提，失败可重试或切本机朗读。额度为零／耗尽只禁新合成，缓存仍可播。本机朗读按实际能力展示播放／暂停／停止和速度；不支持 seek 时不显示可拖动进度及“后退 5 秒”。音频波形若无真实采样只作装饰，不冒充播放定位。自然播放结束记录完成并呈现听力反馈；停止不算完成。

## 词库与导入

左栏为全部词卡与词书，词书菜单包含仅看此书、合并导入、删除；基线与学习词书有用途标记。列表支持单词／释义搜索、四种 FSRS 状态、暂停全部／是／否、总数与分页。列表中显示词、释义来源、词书、状态、到期、编辑／暂停操作。

编辑侧栏有释义（≤1000 字符）、例句（≤5000 字符）、暂停开关；统一点击保存提交，取消不改库。行内暂停是立即操作，失败恢复原样。切卡或关面板时有未保存改动则提供保存／丢弃／继续编辑。

导入流程：选词卡或词表 → 词表选基线／学习用途 → 新建或合并目标 → 选择文件 → 开始导入。新词书默认取文件名，不强制输入名称；同名同类自动合并。文件未选时禁提交，取消文件选择不开始导入。处理期间展示可用进度，导入结果持久化，可展开行级错误。

删除弹窗提交前计算未复习卡数与有历史卡数；无历史卡可删除，有历史卡保留并永久归档暂停。提交时重新核对，计数变化则更新确认内容。不能通过普通暂停开关把删除保留卡恢复到队列；历史可在数据恢复流程处理。

## 生词箱

卡片展示词、可选释义及 AI 标签、上下文高亮、来源和标记时间。缺释义仍可处理，来源文章不存在时禁跳转并保留上下文。选择后才出现上下文操作栏；全选范围是当前结果集，改变筛选会清空选择。加入／忽略以整批事务执行；有过期条目则刷新并提示，不能局部成功后显示整批成功。

## 统计与设置

统计采用设计稿长页面：四项指标、覆盖率趋势、出现／对照组、每周活跃、分阅读／听力的反馈、带可提取率的已学词列表。零样本为“暂无数据”，不得显示 0% 暗示测量结果。

设置分 AI 服务、学习与阅读、实验参数（定位同页高级区域）；补充“外观”放学习与阅读区，支持跟随系统／浅色／深色。滑块配可键盘输入的数值，双端文章长度保持最小≤最大。保存前只改草稿；撤销回到已保存值，关闭有脏数据时提醒。保存配置不发测试调用，密钥留空保持、显式清除与替换是不同动作。

## 通用状态

加载使用 skeleton／进度与可访问标签；错误给出可恢复操作；Snackbar 不替代持久错误说明。modal 限制焦点，Escape 关闭非提交中的面板，关闭后回原控件。长列表滚动／虚拟化，后台 IO 不阻塞 UI。详情不存在、数据库不可读和网络失败分开提示；“404”只是浏览器映射，不要求桌面呈现 HTTP 概念。
