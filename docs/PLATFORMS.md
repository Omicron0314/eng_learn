# 平台矩阵与交付条件

核实日期：2026-11-02。资料来源和限制见 [GPUI-FEASIBILITY](spikes/GPUI-FEASIBILITY.md)。**上游列出支持 ≠ 词间已经构建／实机验收。** 当前 Linux 桌面端已有实现与局部证据；Windows/macOS 未实机验收；Web 与移动端未实现，属远期规划（[D47](DECISIONS.md)）。

## 交付路线

| 平台 | 上游可见证据 | 词间路线 | 发布前需有的证据 |
| --- | --- | --- | --- |
| Linux | Kit 声明支持；Material 有 CI，实机记录不足 | 第一开发平台，Wayland／X11 单列 | 构建、GPU启动、中文IME、选文件、数据库、音频、打包／重启 |
| Windows | Kit 声明支持；Material 有 CI | 桌面首轮范围 | 实机输入、缩放、凭据、音频与打包 |
| macOS | Kit 声明支持；Material 有 CI | 桌面首轮范围 | Intel/Apple Silicon 按实际构建分别登记；输入、字体与音频 |
| 桌面浏览器 | Kit／Material 有共享 WASM gallery | 远期（R18，暂不实施） | GPU／浏览器版本、存储持久化、文件导入、CORS、可访问性 |
| Android / iOS 浏览器 | 小屏UI可表达，未见本项目实机结果 | 远期（R18，暂不实施） | 真机触摸、软键盘、滚动、音频权限、后台恢复、内存压力 |
| Android 原生 | 未从本次来源确认受支持的 GPUI 后端 | 远期（R19 验证 → R20 条件实施，暂不实施） | 渲染／输入／系统集成原型与可重复构建 |
| iOS 原生 | 未从本次来源确认受支持的 GPUI 后端 | 远期（R19 验证 → R20 条件实施，暂不实施） | 同上，另验证生命周期／音频会话和签名环境 |

上表前四行（Linux、Windows、macOS）是本轮交付范围；浏览器与移动行自 2026-11-05 起降为远期规划（[D47](DECISIONS.md)），只保留能力事实和未来门槛，不构成本轮交付承诺。

Linux 先验不免除其他桌面验收；R17 为每个桌面平台给出通过／阻塞，不以一个平台冒充全部通过。Web 是同一产品能力的适配，不要求恢复 Next.js 服务端架构；该适配归远期 R18。原生移动验证失败须记录具体缺口和备选评估，不能自行换成 React Native／Tauri／Flutter。

## 平台接口与降级

“Web/WASM默认”列属于远期（R18）设计约束；本轮只实现桌面列，不因该列已写定而视为已交付。

| 能力 | 桌面默认 | Web/WASM默认 | 无能力时 |
| --- | --- | --- | --- |
| Repository | SQLite＋本地用户目录 | IndexedDB事务实现；若 R00 证明 SQLite WASM/OPFS 更适合可决策替换 | 明确不支持持久化，不能静默用易失空库冒充保存 |
| BlobStore | 文件缓存 | IndexedDB/OPFS blob，依据实测 | 存储满时可清缓存并保留学习数据 |
| 文件选择 | 系统选择器 | File API／文件下载 | 提供错误与替代格式说明 |
| 远端 LLM/TTS | 原生 HTTP transport | fetch；仅连允许 CORS 的自带端点 | 给出 CORS／连接说明；可配置用户自有代理，不内置托管网关 |
| 凭据 | 系统凭据存储；不可用时会话内 | 默认会话内；不宣称浏览器能隐藏 BYOK | 重启需重新输入，明确状态 |
| 整篇音频 | 原生 AudioPlayer | HTML media/Web Audio适配 | 降级显示实际可用操作 |
| 免费朗读 | 系统英语 voice，按能力检测 | SpeechSynthesis，按能力检测 | 提示未安装／不支持，已有音频仍可播 |
| 快捷键／IME | Kit focus/actions＋系统输入 | Kit web input bridge＋IME | 不以键盘事件模拟中文输入完成验收 |
| 主题／生命周期 | OS主题、窗口与电源事件 | matchMedia、visibility、page lifecycle | 用户显式主题仍可用；回来重新取队列 |

浏览器中的密钥存在客户端运行时，不能沿用设计稿“只在服务端、不下发浏览器”的字面承诺。桌面也不能假称有服务端：应显示“由本机凭据存储保存”；来源说明随平台变化。保存凭据不做测试调用。

桌面已下载内容可离线使用；Web 离线需额外完成入口／字体／图标／WASM 资源缓存与存储恢复测试。PWA 安装图标本身不构成离线能力。云端 AI 操作在离线时即时提示，不能靠旧服务工作线程隐式重试。

## R00 / R19 验证记录模板

记录 OS／架构、GPU与驱动、引擎和Material完整revision、依赖图、命令、输入法、截图、可访问树、失败日志和可重现步骤。需要实际运行的项目不能仅勾选“cargo check通过”。

R00 先做桌面消费者与 WASM 最小窗口、中文输入／点击词片段／sheet、数据库契约可实现性、音频 seek/rate、FSRS状态转换。无桌面运行环境的系统保留阻塞项；不阻塞先在可用系统推进，但不宣布该平台交付。WASM 部分自 2026-11-05 起只保留既有结论，不再作为本轮门槛。

远期：R19 对 Android/iOS 分别验证，得到可维护路径才建立原生入口。狭窄桌面窗口和浏览器设备模拟不能抵作移动原生验证。

## 多端数据边界

每个设备独立 profile 与设备ID。备份恢复使用显式版本化包，恢复到新 profile，避免覆盖活跃数据。UUID、append-only 事件和时间戳为未来同步提供素材，但它们不解决冲突：同步需要幂等、删除传播、同卡并发评分的确定性重放、凭据排除和恢复协议，归 R21。
