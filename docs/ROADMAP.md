# 路线图

本轮完成文档重规划；以下是后续实施路线，不是既有交付。详细依赖见 [BACKLOG](BACKLOG.md)。

**2026-11-05 范围修订**：当前阶段只做 Linux 桌面（G0–G3）。G4–G6 的 Web/WASM、移动原生与跨端同步改为远期规划（[D47](DECISIONS.md)）；Windows／macOS 与真实 IME／触摸等本机无法取证的项从验收中删除，证据改由 CI 承担（[D54](DECISIONS.md)）。

| 阶段 | 任务 | 交付与退出条件 |
| --- | --- | --- |
| G0 技术验证 | R00 | 最小消费者、Git依赖／patch、FSRS转换与存储方案；能力探针在 CI 可重复执行 |
| G1 基础 | R01–R05 | Rust workspace、纯领域与事务存储、M3主题／导航、可配置AI；空库可启动，fmt/clippy/test 全绿 |
| G2 学习闭环 | R06–R12 | 导入→复习→生成→阅读／点词→生词整理→音频；错误路径与幂等有 CI 证据 |
| G3 完整桌面产品 | R13–R17 | 今日／热力图、统计、设置、迁移备份；CI 产出设计截图、release 性能与 Linux 包启动冒烟 |

G2各任务按依赖可形成小闭环，不要求一次替换全部旧Web。G3只交付 Linux；CI 是唯一验收通道，本机运行只用于开发排错。

## 验收通道

只有一个：CI 的 Linux runner。需在 CI 里完成的作业：fmt／clippy／test、Xvfb 巡检与截图、release 性能记录、低空间与中断故障注入、包构建与启动冒烟。

Windows／macOS、真实中文 IME、触摸、读屏、人工听感、付费真实模型质量不在本轮范围，既不算通过也不算阻塞（[D54](DECISIONS.md)）。本机不能产生以上证据，不得为凑状态把它们写回 AC。

## 体验验证

桌面闭环可用后开始2–4周自用，观察每周活跃、阅读完成、反馈、Again率与样本量，同时记录生成内容和系统朗读的主观问题。主观体验不作为任务完成条件。

## 后续候选

逐句重复／听写、原创考试题型、内容导入、词汇初测、FSRS参数优化、输出练习与口语功能需单独规格。内置词书需要可分发许可；账号、托管AI和计费需要新的产品决定。它们不作为设计稿功能的隐含依赖。

## 变更约束

范围伸缩只能由用户决定。把 Web／移动端降为远期、把 Windows／macOS 与真实 IME／触摸移出验收，都是用户明确的范围决定，不等同于判定这些端不可行，也不删除设计稿对应的画板。旧代码退役以迁移／恢复与功能验收为条件，不以新工程能打开窗口为条件。
