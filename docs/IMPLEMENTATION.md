# 重构实施证据

用户已授权实际实现和原子提交，要求主代理直接执行、不使用 subagent，人工操作集中在最终交付清单。本文记录实施事实，不代表各规格全部 AC 已通过。

## 工程与验证方法

根 workspace 使用 Rust 1.99.1 和锁定的 GPUI Kit/Material revisions、九项共享引擎补丁。领域、端口、应用、存储、provider、平台和 UI 分层，桌面通过应用命令接入真实 SQLite。独立 `spikes/r00` 保留消费者验证；原 Web 产品和用户已有改动保留。

本地使用 `CARGO_TARGET_DIR=spikes/r00/target` 复用编译缓存，不依赖外部源码 checkout。Rust CI 已建立，尚无远端运行结论。`tools/check-rust-boundaries.py` 检查领域 IO、时间 feature 和生产代码引用测试替身的情况。

## 2026-11-05 全功能巡检

在 Xvfb 隔离数据目录中通过 `seed_acceptance_fixture` 建立原创 fixture，使用 loopback OpenAI-compatible/TTS stub，按页面逐项操作并截图。记录见 [ui-fix-tour.json](evidence/rust/ui-fix-tour.json)。本轮修复了：点词后加入复习丢失释义、复习缺释义不自动补全、导入词表入口默认词卡、复习剩余数包含已评分卡、词库行不可选/来源重复、生词箱零选择仍显示批处理栏、生词箱把导入释义标成AI生成、阅读正文首帧被截断、音频自然结束后不能重播、文章无历史/日期筛选/已读状态、统计无单点覆盖率/已学词分页、完成阅读后统计不刷新、备份成功提示固定写成不含音频等。对应测试覆盖见 `cargo test --workspace`（UI 31项、存储44项、桌面 tour/e2e）。

学习步骤原先固定为 ts-fsrs 的 1m/6m/10m，且等待态需要离开页面再进入。现在按 Anki 26.09.3 默认逻辑：learn 1m/10m、relearn 10m、Hard 停在当前步（首步 5.5m、末步 10m）、Good 推进并在末步毕业到 1d、Easy 毕业到 4d；主队列的 Review/New 按 Anki 默认 MixWithReviews 交错；主队列为空时 20 分钟 learn-ahead 内的 learning/relearning 直接进入队列，允许提前评分，不再显示倒计时。领域测试覆盖步骤序列、提前评分和队列顺序，存储测试覆盖 ahead 队列与超窗口等待，UI 测试覆盖 1m/6m/10m/4d 显示。复习卡仍使用 FSRS。

## 最近验证

迁入与规范 JSON 哈希接入后，workspace 测试和 clippy 分阶段通过。词库增量验证中存储 38 项、桌面 5 项测试通过；包括原创万词分页、基线不建卡、过期删除预览、暂停不改调度、报告重开。随后补测了历史未知格式报告不会遮住新的有效导入报告。领域 22 项单测及 64 组 TS 调度向量仍分别记录，不将它们混为实机验收。

UI harness 已覆盖导航、设置入口及 Tab 焦点；新词库用例在360/1000dp下实际点击和输入，验证保存冲突后保留草稿、Escape/放弃/返回以及 Enter 搜索。该用例与 workspace `clippy --all-targets` 通过；它不证明真实 IME、完整视觉设计或所有平台行为。词库存储与界面分别提交为 `20aaf0d`、`79ae5a9`。

设置增量验证：领域24项、调度向量集1项、存储39项、桌面8项通过；最新UI套件6项及工作区clippy通过。UI用例覆盖独立保存、冲突保留输入、确认重新载入、服务切换、返回/关闭保护、360/1000dp实验定位，以及两个窗口按各自主题绘制而不改应用全局色板。草稿交互和窗口主题分别提交为 `2c4ca1a`、`669a254`。

系统凭据适配器新增 `RuntimeSecrets`：每次读写在系统凭据库可用时使用它，失败后才写入会话内存，并把来源返回设置页。测试通过注入的内存/不可用后端覆盖两条分支；桌面测试使用 `open_for_tests` 强制会话模式，绝不读写操作者的真实凭据。该行为仍需在 macOS/Windows 凭据服务上单独验收。

流式导入测试覆盖1/2/7/8192字节读取块、BOM/空行、中文列名、多行引号、行号、哈希和资源错误。`615dbcf`修复单字节读取时BOM空记录消耗表头识别的问题。原始文件不整读，但归一化批次仍在内存中，不能声称总内存有固定上限。

[本地模型端到端记录](evidence/rust/local-model-e2e.json) 使用 loopback stub、临时学习库和会话密钥，证明的是协议/事务/日志链路，不是模型质量。

[R17 桌面验收记录](evidence/rust/r17-desktop.json) 使用临时学习库和 release 二进制，截图与限制见该记录；它不是完整 R17 通过。

桌面构建入口 `tools/build-desktop.sh` 默认构建 debug（target 默认 `spikes/r00/target`），也可用 `--release`；它把 `~/.local/bin/cijian-desktop` 重新连接为指向构建产物的符号链接，并刷新 `~/.local/share/applications/cijian.desktop` 与图标。因此后续在同一 `CARGO_TARGET_DIR` 下成功构建，启动器会自动运行新产物；`cargo clean` 或更换 target 后重跑脚本即可。`tools/package-desktop.sh` 只构建 release 并刷新 `dist/cijian-desktop-linux-x86_64.tar.gz`，不改动启动器；启动器默认保持 debug。两者都是本地构建/分发辅助，不是签名安装器或自动更新方案。

[原生音频证据](evidence/rust/native-audio.json) 使用临时目录生成的低音量原创 WAV，验证真实输出设备、暂停、定位、1.25 倍速、停止和自然结束。另以系统 espeak-ng 1.52.0 将原创英文句子合成为可解码 WAV。本机安装已记入用户运维日志；没有改动音频设备、服务或用户配置。两个设备测试默认 ignored，需在明确的本机能力验证中单独执行；不把人工听感标为通过。

UI 已按 `docs/cijian-m3.html` 的脚本后画板重做：96dp 导航轨、28dp 分区面板、Today/Stats 主辅双栏、Review 大卡与四段评分、Articles 生成/列表、Library 三栏与编辑 side sheet、Inbox 多选卡片、Settings 分类 rail/滑块/固定保存栏、Reader 点词 side sheet 与移动端 bottom sheet。界面字体由画板内嵌 Roboto Flex/Mono 子集静态实例化并附 OFL；中文字体仍走系统 fallback。截图和限制见 [UI 重做证据](evidence/rust/ui-redesign.json)；这是视觉/交互人工对照，不是自动像素 diff，也不证明真实 IME、触摸或其他平台。`cargo test --workspace`、clippy 与 fmt 通过；原有行为测试使用的稳定 ID 得到保留，设置页改为分类后对应测试改为先进入学习页，实验入口仍从统计页定位。

窗口 chrome 追加 48dp 应用标题栏：Linux 客户端装饰下显示最小化、全屏、关闭，macOS/Windows 分别保留原生交通灯与平台 caption 按钮；浅色 niri 截图与 360/1000dp 布局、全屏切换测试见 [窗口 chrome 证据](evidence/rust/window-chrome.json)。macOS/Windows 仅完成代码路径适配，未做实机验收。

测试只用原创、临时学习库和测试凭据。没有调用真实付费 AI、读取私人学习库或迁移真实密钥。APKG 使用临时只读集合，不迁入媒体或 Anki 调度；WordNet 数据和字体保留第三方许可。
