# T3.1 `selectTargets`

## 目标

按优先级从当天复习数据中选出本篇文章的目标词,并随机留出 control 组,用于验证 H3。

## 范围与非范围

**范围**

- 纯函数 `selectTargets`(`packages/core/src/generation/select-targets.ts`):
  - 候选只来自未暂停的卡片,排除短语(词元含空格);
  - 优先级桶:
    1. 今天有 Again 或 Hard 评分的词;
    2. 今天首次学习的词(今天有 `state_before = new` 的日志);
    3. `review` 状态且 `due ≤ now` 的词;
  - 每个桶内按可提取率升序,相同时按 `lexemeId` 升序(保证确定性);一个词只进入它满足的最高优先级桶;
  - 排除:近 3 天内在文章中以 `exposed` 角色出现的总次数 ≥3 的词(`article_targets.occurrences` 求和);
  - 取前 `n` 个(`n = settings.targetCount`,默认 8);
  - 从选中的词中用 `rng` 随机抽取 `round(选中数 × controlRatio)` 个标为 `control`,其余为 `exposed`。
- 候选为空时返回空结果,由调用方给出“先去复习几张卡片”的提示。
- 服务 `generationService.selectTargetsForUser(deps)`:读取卡片、今天的复习日志、近 3 天的 `article_targets`,调用纯函数。

**非范围**:按主题或体裁选词;跨文章的词频均衡。

## 接口

```ts
type TargetCandidate = {
  lexemeId: string; lemma: string; card: SrsCard; suspended: boolean;
  todayRatings: Rating[]; introducedToday: boolean;
};
type SelectedTarget = { lexemeId: string; lemma: string; role: "exposed" | "control"; bucket: 1 | 2 | 3 };
function selectTargets(input: {
  candidates: TargetCandidate[];
  recentExposure: Map<string, number>;   // lexemeId -> 近 3 天 exposed 出现次数
  now: Date; n: number; controlRatio: number; rng: () => number;
}): SelectedTarget[];
```

## 验收标准

- AC1:三个桶都有候选时,结果按桶 1 → 2 → 3 排列;同时满足桶 1 与桶 2 的词只出现一次,归入桶 1。
- AC2:桶内按可提取率升序。
- AC3:近 3 天 exposed 出现 3 次的词被排除,2 次的不被排除;以 control 角色出现的次数不计入。
- AC4:候选 8 个、`controlRatio=0.2` 时,恰好 2 个 `control`;相同 `rng` 种子结果完全相同,不同种子会改变 control 的选择。
- AC5:候选少于 `n` 时返回全部候选;候选为 0 时返回空数组。
- AC6:暂停的卡片、短语、`new` 状态且今天未学习的词不会被选中。
- AC7:集成:构造今天的复习日志与历史文章后,`selectTargetsForUser` 的结果与预期一致。

## 测试计划

- 单元:`selectTargets`(AC1–AC6),使用带种子的 rng。
- 集成:`selectTargetsForUser`(AC7),`:memory:` 库。

## 依赖与风险

- 依赖 T1.2、T2.3。
- 风险:每次只选 8 个词、其中 2 个作对照,H3 的样本积累较慢;`plan.md` 已说明 H3 仅作参考。
