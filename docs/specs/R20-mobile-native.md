# R20 · 移动原生产品实现

任务状态以 [BACKLOG](../BACKLOG.md) 为准。阶段：G5（远期，暂不实施）。依赖：R19、R17。

## 目标与范围

仅对R19通过的平台建立原生入口和适配器，共用domain/app/ui与备份格式。

设计追踪：screen-mobile与其余功能的紧凑适配。通用约定见 [specs/README](README.md)；未列出的后续功能不在本任务扩展。

## 验收标准

- **AC1**：R19相应平台有明确go，未通过系统不进入实现或宣称支持。
- **AC2**：七个入口／学习闭环与桌面同语义，移动布局按UI-SPEC，列表／弹层可触摸访问。
- **AC3**：生命周期中断不丢评分、不重复合成／事件；数据库恢复与系统权限行为可验证。
- **AC4**：离线内容、备份／恢复、音频和主题在实机完整通过；签名与发布权限分开处理。

## 验证与交付

共用合同＋原生实机端到端、断网／后台／重启、缩放与读屏、打包安装。

每条AC在交付记录中对应测试、截图或平台运行证据；需要实机的条目不可用静态审查抵替。变更业务写入时同时断言events；失败路径检查不产生部分成功。

## 边界与风险

不把WebView套壳默认等同GPUI原生；若实现形态变化需更新决策与用户范围。

执行中发现设计或契约变化时更新 [DECISIONS](../DECISIONS.md) 和相应规格；没有实证的能力标未验证。
