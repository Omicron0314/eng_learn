# T6.1 难度反馈与“不自然”标记

## 目标

收集每篇文章的难度反馈(H2)与“不自然”标记(供以后调提示词),全部写入 `events`。

## 范围与非范围

**范围**

- 难度反馈组件 `DifficultyFeedback`:三个按钮“太难 / 刚好 / 太简单”,参数 `after: "reading" | "listening"`。
  - 阅读:点击“读完了”(或自动记录读完)后在文末显示;
  - 听力:由 T5.2 在播放结束后显示。
  - 可以改选,每次点击写一条 `difficulty_feedback` 事件;统计时同一文章同一 `after` 取最后一次。
- “标记不自然”:文末按钮打开对话框,列出文章的所有句子(复选框)和可选备注(≤200 字);提交后每个选中的句子写一条 `unnatural_flag` 事件(`sentenceIndex`、`note`);不选句子只写备注时写一条不带 `sentenceIndex` 的事件。
- 服务 `feedbackService.submitDifficulty`、`feedbackService.flagUnnatural`,payload 经 T1.4 的 schema 校验。
- 查询:`latestDifficulty(articleId)`(供 T6.3 与界面显示当前选择)。
- API:`POST /api/articles/[id]/feedback`。

**非范围**:根据反馈自动调整档位(Phase 2);在弹层中逐词标记不自然。

## 接口

```ts
type Difficulty = "too_hard" | "just_right" | "too_easy";
function submitDifficulty(deps: AppDeps, input: { articleId: string; value: Difficulty; after: "reading" | "listening" }): void;
function flagUnnatural(deps: AppDeps, input: { articleId: string; sentenceIndexes: number[]; note?: string }): { events: number };
function latestDifficulty(deps: AppDeps, articleId: string): Partial<Record<"reading" | "listening", Difficulty>>;
```

## 验收标准

- AC1:提交反馈写 1 条 `difficulty_feedback` 事件,payload 正确;不存在的文章返回 `NOT_FOUND`。
- AC2:同一文章先选“太难”再选“刚好”,事件有 2 条,`latestDifficulty` 返回“刚好”。
- AC3:阅读与听力的反馈分开记录、分开返回。
- AC4:选中 3 个句子提交“不自然”写 3 条事件,`sentenceIndex` 正确;只写备注写 1 条;句子序号越界时拒绝,不写事件。
- AC5:备注超过 200 字被拒绝。
- AC6(e2e):读完文章后出现难度反馈,点击“刚好”后按钮显示为已选中;打开“标记不自然”对话框,选择一句提交成功。

## 测试计划

- 集成:`feedbackService`(AC1–AC5)。
- e2e:`feedback.spec.ts`(AC6)。

## 依赖与风险

- 依赖 T3.3。
- 风险:反馈依赖用户主动点击,样本可能少;H2 的结论需结合 `unknownRatio` 一起看。
