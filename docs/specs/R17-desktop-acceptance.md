# R17 · 桌面完整验收与本地打包

任务状态以 [BACKLOG](../BACKLOG.md) 为准。阶段：G3。依赖：R14、R15、R16。

## 目标与范围

交付 Linux 构建与 CI 验收记录、包、使用说明、迁移／回退演练和残留问题，不自动发布。

设计追踪：全部桌面画板与窄窗口。通用约定见 [specs/README](README.md)；未列出的后续功能不在本任务扩展。

## 验收标准

- **AC1**：设计追踪表每行有截图与交互证据，浅深、缩放、长文本、空／加载／错误齐全；自动驱动落地前允许本机 Xvfb 截图，须标注来源。
- **AC2**：导入→复习→文章→点词→inbox→音频→统计闭环与事件对账由自动化巡检执行，重启后保留。
- **AC3**：CI 在 Xvfb（X11、软件渲染）下覆盖全部入口与状态；Wayland、Windows／macOS、IME 与触摸不在本轮 AC。
- **AC4**：release 构建的1万词交互／帧时／空闲行为在 CI runner 上测量并记录机型，不以开发模式或上游目标替代。
- **AC5**：CI 构建的 Linux 包可启动、可恢复备份；升级路径与真实 AI 质量、长期效果另记。

## 验证与交付

TESTING规定的 CI 作业、GPUI harness、Xvfb 巡检截图、release性能trace、包构建与启动冒烟。

每条AC在交付记录中对应 CI 运行结果；本机用同一条命令复现用于排错，不单独作为验收证据（[D56](../DECISIONS.md)）。变更业务写入时同时断言events；失败路径检查不产生部分成功。

执行中发现设计或契约变化时更新 [DECISIONS](../DECISIONS.md) 和相应规格；没有实证的能力标未验证。
