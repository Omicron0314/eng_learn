# T4.1 点词弹层与语境释义(缓存)

## 目标

点击正文中的任意词,弹出词元、发音与“在本句中的释义”;释义由 LLM 生成并按(词元,句子)缓存,第二次不再调用 LLM。

## 范围与非范围

**范围**

- 前端:点击 T3.3 渲染的 word `<span>` 打开弹层(移动端为底部抽屉),显示:
  - 原词与词元(词元取 `Lemmatizer` 的首个候选,服务端计算);
  - 发音按钮:用浏览器 SpeechSynthesis 朗读词元(零成本);若释义返回了音标则一并显示;
  - 语境释义:加载中 → 释义 / 失败提示;
  - 三个按钮的位置(行为在 T4.2 实现)。
- 句子:用 T2.1 的 `sentenceAt(body, start)` 取得。
- 服务 `glossService.getGloss(deps, { lemma, sentence, surface, articleId? })`:
  1. upsert lexeme(`lemma`,`pos=''`);
  2. `context_hash = sha256(规范化后的句子)`,规范化为 trim、合并连续空白、弯引号转直引号;
  3. 查 `gloss_cache(lexeme_id, context_hash)`,命中直接返回;
  4. 未命中:用 `prompts/gloss.v1.md` + `completeJson`(purpose `gloss`)生成,写入 `gloss_cache`,写 `llm_calls`;
  5. 每次点击写 1 条 `lookup` 事件(含 `cacheHit`)。
- 释义 schema:`{ lemma: string, pos: string, meaningZh: string, meaningEn?: string, ipa?: string }`,`meaningZh` 不超过 30 字。
- API:`POST /api/gloss`。

**非范围**:三个按钮的行为(T4.2);整句翻译;词典数据源。

## 接口

```ts
type Gloss = { lemma: string; pos: string; meaningZh: string; meaningEn?: string; ipa?: string };
function getGloss(deps: AppDeps, input: {
  lemma: string; surface: string; sentence: string; articleId?: string;
}): Promise<{ lexemeId: string; gloss: Gloss; cacheHit: boolean }>;
function contextHash(sentence: string): string;
```

提示词 `prompts/gloss.v1.md`(新提示词,需人审),草稿:

```
System: You explain English words to Chinese learners, in the context given.
Word: {surface} (base form: {lemma})
Sentence: {sentence}
Explain the meaning of the word in this sentence only.
Output JSON only: {"lemma": string, "pos": string, "meaningZh": string, "meaningEn": string, "ipa": string}
meaningZh: at most 30 Chinese characters. meaningEn: one short phrase.
```

## 验收标准

- AC1:同一(词元,句子)第二次请求不调用 LLM(FakeLLM 调用次数不变),`cacheHit=true`。
- AC2:句子只有空白差异或弯 / 直引号差异时命中缓存。
- AC3:同一词元、不同句子会再次调用 LLM,产生两条缓存。
- AC4:LLM 两次非法输出时返回 `LLM_OUTPUT_INVALID`,不写缓存,`llm_calls` 有记录,弹层显示“释义生成失败,可重试”。
- AC5:每次点击写 1 条 `lookup` 事件,payload 中的 `lemma`、`sentence`、`cacheHit` 正确。
- AC6(e2e):在文章页点击一个词,弹层显示 FakeLLM 返回的中文释义与词元;点击另一处同一句中的同一个词,不再调用 LLM。
- AC7:`went` 点击后弹层显示词元 `go`。

## 测试计划

- 单元:`contextHash`(AC2)。
- 集成:`getGloss`(AC1、AC3–AC5,AC7)。
- e2e:`lookup.spec.ts`(AC6)。

## 依赖与风险

- 依赖 T3.3、T0.3。
- **待确认**:新提示词 `gloss.v1`;弹层组件可能需要新增 shadcn/ui 依赖(如 `@radix-ui/react-popover`)。
- 风险:词元不准时缓存键也会偏;同形异义词按“首个候选”取词元,由释义中的 `lemma` 字段给出 LLM 的判断,界面以 LLM 的为准显示。
