# T2.2 基线词表导入

## 目标

导入用户自带的 TXT / CSV 词表,标为“基线(已知)”或“学习词书”。基线词进入已知词集合,不建卡;学习词书建为复习卡片。

## 范围与非范围

**范围**

- 解析:`parseWordListLine`(`packages/core/src/lexicon/wordlist.ts`),规则按 S4 结论;`fixtures/wordlist/cases.json` 全部用作测试。
- 服务 `importWordList(deps, { fileName, bytes, name, kind })`:
  - 一个事务内:创建 `word_lists` 记录;对每个条目 upsert lexeme(`headword`,以及 S4 规定要纳入的变体),写 `word_list_items`;
  - `kind="study"`:同时按 T1.1 的规则为每个词建卡(`deck=name`、`origin="import"`,已有卡片则跳过),释义来自词表中的 `meaning`(如有);
  - 写 1 条 `import` 事件(`source="txt"` 或 `"csv"`,`kind`,`listId`,计数)。
- 重复导入同名同类词表:提示已存在;选择“合并”时只新增缺少的词。
- `/library` 的导入表单增加“词表”类型,选择“基线(已知)”或“学习词书”。
- 仓储 `WordListsRepo`:`listBaselineLemmas(userId)` 返回所有基线词元(供 T2.3)。
- 创建 `docs/licenses.md`:写明 MVP 不内置词表,用户自带词表只在本地使用、不随仓库分发;若 S1 引入了词形数据,一并记录。

**非范围**:内置词表;短语参与覆盖率计算;词表编辑界面。

## 接口

```ts
type WordListKind = "baseline" | "study";
type WordListImportResult = {
  listId: string; parsed: number; skippedLines: { line: number; raw: string }[];
  duplicates: number; phrases: number; wordsAdded: number; cardsAdded: number;   // cardsAdded 仅 study
};
function importWordList(deps: AppDeps, input: {
  fileName: string; bytes: Uint8Array; name: string; kind: WordListKind; mergeIfExists?: boolean;
}): Promise<WordListImportResult>;
```

## 验收标准

- AC1:S4 的全部规则用例通过。
- AC2:导入合成基线词表(`fixtures/wordlist/baseline-sample.txt`,约 500 词,含各类写法)后,`listBaselineLemmas` 返回去重后的词元,数量与预期一致;未建任何卡片。
- AC3:以 `study` 导入同一文件:每个非短语词条建 1 张卡,已有卡片跳过;短语条目也建卡(作为复习对象),但在 T3.1 中不会被选为目标词。
- AC4:无法解析的行出现在 `skippedLines` 中,带行号,不中断导入。
- AC5:重复导入同名同类词表且不合并时返回提示、不写数据;合并时只新增缺少的词。
- AC6:每次导入恰好 1 条 `import` 事件;失败时词表、条目、卡片、事件都不落库。
- AC7:导入基线词表后,对 `fixtures/analyzer/samples/` 中的四级难度样例文章可以计算覆盖率(集成测试串起 T2.1 + 本任务 + T2.3 的已知集合)。
- AC8(手动,不进 CI):作者用真实的高中 3500 词表导入,记录解析统计与一篇样例文章的覆盖率,写入 `docs/spikes/S4.md` 附录。

## 测试计划

- 单元:`parseWordListLine`(AC1)。
- 集成:`importWordList` 使用 `:memory:` 库(AC2–AC7)。

## 依赖与风险

- 风险:变体是否纳入基线会影响覆盖率,按 S4 结论执行,改动记入 `docs/DECISIONS.md`。

增加 attached slash 变体与独立音标组合的归一用例；组合条目与分行 color/colour 的词元集合相同。AC6 注入导入事务中途失败，断言 lists/items/lexemes/cards/events 全部回滚。AC7 使用原创合成文章（非真实四级语料）串联导入、KnownSet、analyzeText，并明确语言质量未验。

词表导入返回 wordsAdded 与 cardsAdded 分离；基线新增词、零建卡及合并只增新词在 UI 明确显示并由 E2E 验证。
