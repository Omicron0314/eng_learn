# T2.3 KnownModel v0(确定性已知词集合)

## 目标

按 `docs/SPEC-CORE.md` §4 构建确定性的已知词集合,供 `analyzeText` 计算覆盖率。

## 范围与非范围

**范围**

- `packages/core/src/knowledge/known-set.ts`(纯函数):

  已知词 = 基线词元
  ∪ 状态为 `review` 且 `retrievability(now) ≥ 0.8` 的卡片词元
  ∪ `lexeme_marks.status = known` 的词元
  ∪ 本次目标词(只含 exposed)

  排除:`lexeme_marks.status = unknown`、标记时间在近 `recentUnknownDays`(默认 14 天)内、且标记之后该词的卡片没有复习记录的词元。排除不作用于本次目标词。
- 阈值 0.8 与 14 天作为参数传入,默认值定义为常量。
- 服务 `knowledgeService.getKnownSet(deps, { targets })`:从仓储读取基线词元、卡片调度字段、标记状态与每张卡片最近一次复习时间,调用纯函数。
- 仓储 `LexemeMarksRepo.listByUser(userId)`(读;写入在 T4.2)。

**非范围**:概率化模型;按词频估计未见词。

## 接口

```ts
type KnownInput = {
  baselineLemmas: Iterable<string>;
  cards: { lemma: string; card: SrsCard; lastReviewAt: Date | null }[];
  marks: { lemma: string; status: "known" | "unknown"; markedAt: Date }[];
  targets: string[];
  now: Date;
  minRetrievability?: number;    // 默认 0.8
  recentUnknownDays?: number;    // 默认 14
};
function buildKnownSet(input: KnownInput): KnownSet & { size: number };
```

## 验收标准

- AC1:只在基线中的词为已知;不在任何来源中的词为未知。
- AC2:`review` 状态、可提取率 0.81 的卡片词为已知;0.79 为未知;`learning` / `new` 状态无论可提取率都不算。
- AC3:标记“认识”的词为已知。
- AC4:基线中的词在 3 天前被标记“不认识”且之后没有复习 → 未知;之后复习过 → 已知;标记已超过 14 天 → 恢复按其它来源判断。
- AC5:目标词即使被排除规则命中也为已知。
- AC6:同一输入多次调用结果相同(不依赖系统时间)。
- AC7:集成:导入基线词表、建若干卡片并复习、做标记后,`getKnownSet` 的结果与逐条规则推导一致。

## 测试计划

- 单元:`buildKnownSet`(AC1–AC6),使用固定 `now` 与手工构造的卡片状态。
- 集成:`knowledgeService`(AC7)。

## 依赖与风险

- 依赖 T2.2、T1.2。
- 风险:“近期”与 0.8 阈值是经验值,自用阶段可根据 H2 指标调整,改动记入 `docs/DECISIONS.md`。
