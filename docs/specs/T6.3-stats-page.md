# T6.3 `/stats`

## 目标

展示学习统计与 H1–H3 的验证指标,数字必须与 `review_logs`、`events` 对账一致。

## 范围与非范围

**范围**

- 学习:
  - 今日 / 本周新学数(`state_before = new` 的复习日志条数)与复习数(全部复习日志条数);周从周一开始,按设置的时区与日界;
  - 已学词列表:`reps > 0` 的卡片,按首次复习时间倒序,显示词、释义、状态、可提取率;分页。
- 文章:
  - coverage 趋势:按生成日期的文章 coverage(折线,自绘 SVG,不引入图表库);
  - `unknownRatio` 中位数(近 7 天 / 全部)。
- 验证指标:
  - H1:近 4 周每周活跃天数(有任意事件的不同天数);文章阅读完成率 = 有 `article_complete` 的文章数 ÷ 有 `article_open` 的文章数;
  - H2:难度反馈分布(每篇文章每种 `after` 取最后一次),“刚好”占比;
  - H3:T6.2 `computeExperiment` 的结果(两组样本数、Again 率、差值),注明“样本小,仅作参考”。
- 每个指标旁显示 plan 中的初始目标值(如“目标:每周 ≥5 天”)。
- 纯函数放 `packages/core/src/metrics/stats.ts`,服务 `statsService.getStats(deps)` 读取数据。

**非范围**:导出报表;自定义时间范围。

## 接口

```ts
type StatsView = {
  learning: { today: { newLearned: number; reviews: number }; week: { newLearned: number; reviews: number } };
  learnedWords: { lemma: string; meaning?: string; state: CardStateName; retrievability: number }[];
  coverageTrend: { date: string; coverage: number }[];
  unknownRatioMedian: { last7d: number | null; all: number | null };
  h1: { activeDaysPerWeek: { weekStart: string; days: number }[]; completionRate: number | null };
  h2: { distribution: Record<Difficulty, number>; justRightRate: number | null };
  h3: ReturnType<typeof computeExperiment>;
};
function getStats(deps: AppDeps): StatsView;
```

## 验收标准

- AC1(对账):在种子数据上,今日 / 本周新学数与复习数等于直接对 `review_logs` 执行的 SQL 计数(测试中同时跑两种查询并比较)。
- AC2:周的边界:周一 4:00(`dayStartHour=4`)之前的复习计入上一周。
- AC3:完成率:打开 4 篇、读完 3 篇 → 0.75;没有打开记录时为 `null`,页面显示“—”。
- AC4:难度反馈同一文章改选时只计最后一次。
- AC5:H3 的数字与 `pnpm report:experiment` 在同一数据库上的输出一致。
- AC6:coverage 趋势按日期升序,每篇文章一个点。
- AC7(e2e):页面渲染出今日新学数、复习数、完成率与 H3 区块,数字与种子数据一致。

## 测试计划

- 单元:`stats.ts` 的纯函数(AC2–AC4、AC6)。
- 集成:`getStats` 与 SQL 对账(AC1、AC5)。
- e2e:`stats.spec.ts`(AC7),使用种子数据库。

## 依赖与风险

- 依赖 T1.4、T6.2、T6.1(H2 数据)、T3.3(完成率数据)。
- 风险:时区与日界设置一旦修改,历史统计口径随之变化;页面注明当前口径。
