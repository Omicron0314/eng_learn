# T1.5 `/settings` 页面

## 目标

让用户查看和修改设置项,并看到 LLM / TTS 的配置状态。设置的存储与默认值已在 T0.2 完成。

## 范围与非范围

**范围**

- 表单字段(含校验范围):
  - `level`:A2 / B1 / B2 / C1,默认 B1,显示“B1(约中国大学英语四级水平)”;
  - `dailyNewLimit` 0–200,`dailyReviewLimit` 0–2000;
  - `requestRetention` 0.70–0.99;
  - `tier`:轻松 / 适中 / 挑战;
  - `articleMinWords` 100–800,`articleMaxWords` 不小于 `articleMinWords` 且 ≤ 1000;
  - `lookupMode`:`markOnly` / `autoAdd`;
  - `ttsDailyCharLimit` 0–200000;
  - `timezone`(IANA 名称)、`dayStartHour` 0–23。
  - `targetCount`、`controlRatio`、`generationMaxRetries` 属于实验参数,放在“高级”折叠区。
- provider 配置(作者后续决定:从 .env 移到设置页手动填写,见 DECISIONS):
  - LLM / TTS 各自可选 provider 类型(`openai-compatible` / `fake`,TTS 另有 `none`)、端点、模型、TTS 声音与 API 密钥;
  - 配置存数据库 `provider_config` 表,保存后立即生效,无需重启;数据库值优先于环境变量;
  - 密钥不下发客户端:视图只返回 `hasApiKey`;输入留空表示保留已存密钥;
  - 不提供“测试连接”按钮(避免产生费用)。
- provider 状态(只读):
  - LLM:生效来源(设置页 / 环境变量 / 未配置)、provider 类型、端点主机名、模型、缺失项;
  - TTS:provider 类型与来源;为 `none` 时显示“使用浏览器朗读”。
  - 不显示 API 密钥的任何部分。
- 保存:`settingsService.update(deps, patch)`,写 `settings_update` 事件(`changed` 为实际变化的键);`updateProviderConfig` 写 `provider.llm` / `provider.tts` 键名,密钥值永不入事件。

**非范围**:多用户;密钥加密存储。

## 接口

```ts
function getSettingsView(deps: AppDeps): { settings: Settings; providers: ProviderStatus };
function updateSettings(deps: AppDeps, patch: Partial<Settings>): Settings;   // 非法值抛 VALIDATION_FAILED
type ProviderStatus = {
  llm: { provider: string; host: string | null; model: string | null; missing: string[] };
  tts: { provider: string };
};
```

## 验收标准

- AC1:每个字段的越界值被拒绝,返回 `VALIDATION_FAILED` 并在表单上显示错误,不写库、不写事件。
- AC2:合法保存后刷新页面值仍在;`settings_update` 事件的 `changed` 只包含实际改变的键;未改变任何值时不写事件。
- AC3:把 `dailyNewLimit` 改为 5 后,`/review` 队列中的新卡不超过 5 张(集成测试)。
- AC4:页面任何响应中不出现 API 密钥的值(仅 `hasApiKey`);缺配时状态显示缺失项,运行期 LLM 调用报“请在设置页配置”的中文错误;启动仅在环境变量配置存在但无效时 fail-fast。

## 测试计划

- 集成:`updateSettings`(AC1–AC3)。
- e2e:`settings.spec.ts`(AC1 的表单展示、AC4)。

## 依赖与风险

- 依赖 T0.2、T0.3、T1.2(AC3)。
- 风险:修改 `timezone` / `dayStartHour` 会改变“今天”的统计口径,界面需提示。

## Web 阶段实施证据与限制

合法设置保存、刷新保留与日上限修改经 E2E / service 测试验证;HTTP 非法参数不落库。provider 配置改为设置页填写后(见 DECISIONS 最新条目):存储/脱敏/保留密钥/事件键名、数据库值优先于环境变量、免重启生效均有 service 与路由测试覆盖。全栈命令与剩余证据缺口见 `docs/WEB-VALIDATION.md`。
