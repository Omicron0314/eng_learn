# R12 · 音频、朗读与播放器

任务状态以 [BACKLOG](../BACKLOG.md) 为准。阶段：G2。依赖：R10、R15。

## 目标与范围

`ensure_audio`、`AudioPlayer`、本地 Kokoro 合成、`audio_sessions`；整篇音频只走本机模型，不再有远程 TTS 端点、密钥与字符额度。

设计追踪：screen-listen、screen-audio-states、悬浮播放器。通用约定见 [specs/README](README.md)。

## 验收标准

- **AC1**：首次播放前先合成**全文**再开始播放，生成中禁止重复提交；失败可重试；缓存命中直接播放。
- **AC7**：正文不叠加查词标记（下划线/方框），查词结果只在面板中展示；双击或拖选正文不得触发查词，慢请求的忙碌提示必须写明具体在做的事。
- **AC2**：缓存 key 区分文章正文与**口音语音**（美音 `af_heart` / 英音 `bf_emma`），缺 blob 时重新合成，同一口音不重复合成。
- **AC3**：本地合成不计字符额度、不写 `audio_reservations`；取消或失败不发布 asset，也不留下半成品 blob。
- **AC4**：整篇播放支持 seek（含后退5秒、暂停中定位、任意档速度下定位）和多档速度；解码必须走可寻址读取，不能用 `BufReader<File>` 伪装成不可寻址流；变速保持音高（WSOLA 时间伸缩，不用 `set_speed` 重采样），不触发重新合成；进度条与总时长按原文时长显示、变速不改变刻度；单词发音不跟随速度档。
- **AC5**：切文章／切口音不会两路播放；切口音立即停止当前播放并回到未生成状态，下次播放使用该口音的缓存或新合成。
- **AC6**：自然结束会话去重并显示听力反馈，停止不记完成；read/listen 反馈独立。

## 验证与交付

`kokoro.py` 助手（固定 `model_q8f16.onnx`）、`tools/install-kokoro.py` 安装校验、`SaveLocalAudio` 存储测试、播放器状态机、取消路径测试、WSOLA 音高与时长测试（220Hz 正弦的过零率）；人工听感不在 AC，CI 只验证解码与播放状态机。本机真实模型与真实声卡用 `#[ignore]` 测试单独运行。

## 边界与风险

CI 不安装模型，因此 CI 只能验证「未安装时给出 `UnsupportedCapability` 且不产生 asset」。模型由本机 venv + espeak-ng 数据驱动，不随桌面二进制分发；专名与数字读音弱于云端神经音色，属已知限制（D64）。
