# T5.1 音频生成与缓存

## 目标

文章页一键生成整篇音频,按文本哈希缓存,相同文本与相同语音配置不重复合成;未配置 TTS 服务商时退回浏览器朗读。

## 范围与非范围

**范围**

- 服务 `audioService.ensureAudio(deps, articleId)`:
  1. `TTS_PROVIDER=none`:返回 `{ mode: "browser", text }`,不写库;
  2. 否则 `text = 标题 + "\n\n" + 正文`;`text_hash = sha256(provider | model | voice | text)`;
  3. 已有该 `text_hash` 的 `audios` 行且 blob 存在:直接返回(缓存命中,不写事件);
  4. 行存在但 blob 丢失:重新合成并覆盖 blob;
  5. 未命中:先过 T5.3 的成本护栏并独立持久化预留（失败则不调用）,再调用 `TTSProvider.synthesize`,blob 写入 `audio/<text_hash>.<ext>`,插入 `audios`(`provider`、`voice`、`blob_key`、`duration_s`、`chars`、`created_at`),写 `audio_generate` 事件（reservationId 关联预留）;
  6. 同一进程内对同一 `text_hash` 的并发请求只合成一次(进程内 in-flight 去重)。
- 音频读取 `GET /api/audio/[key]`:从 BlobStore 读取,支持 HTTP Range(Safari 拖动进度需要),返回正确的 `Content-Type`。
- API:`POST /api/articles/[id]/audio` → `{ mode: "server", url, durationS } | { mode: "browser", text }`。
- 真实服务商适配器:按 MVP-EXECUTION 已授权配置驱动的 OpenAI 兼容适配器（分段合成与拼接在内部完成），createTTS 注册 none / fake / openai-compatible；端点、模型、音色来自配置，未做付费实调用。

**非范围**:播放器 UI(T5.2);逐句音频;多音色对话。

## 接口

```ts
type AudioResult =
  | { mode: "server"; audioId: string; url: string; durationS: number | null; cacheHit: boolean }
  | { mode: "browser"; text: string };
function ensureAudio(deps: AppDeps, articleId: string): Promise<AudioResult>;
function audioTextHash(input: { provider: string; model: string; voice: string; text: string }): string;
```

## 验收标准

以下使用 FakeTTS、MemoryBlob 与 `:memory:` 库。

- AC1:同一文章连续请求两次,FakeTTS 只被调用 1 次;第二次 `cacheHit=true`;`audio_generate` 事件只有 1 条。
- AC2:修改 `TTS_VOICE`(或 `TTS_MODEL`)后再请求,哈希变化,重新合成。
- AC3:`audios` 行存在但 blob 被删除时,重新合成并恢复 blob。
- AC4:并发发起 5 个相同请求,FakeTTS 只被调用 1 次。
- AC5:`TTS_PROVIDER=none` 时返回 `browser` 模式,不调用 TTS、不写库。
- AC6:切换 TTS 实现只需修改环境变量:同一测试分别以 `TTS_PROVIDER=fake`、`none` 构造 `AppDeps`,业务代码无需改动。
- AC7:`GET /api/audio/[key]` 带 `Range: bytes=0-99` 时返回 206 与 100 字节;key 不存在返回 404。
- AC8:代码与测试中不出现服务商的具体模型名或音色名(T0.1 的边界检查)。

- 集成:`ensureAudio`(AC1–AC6)、音频路由(AC7)。

## 依赖与风险

- 依赖 T3.2、T0.3;T5.3 的护栏已实施，含调用前独立持久化预留，不再使用放行占位。
- 真实 TTS 实施选择已由作者授权，见 MVP-EXECUTION；真实费用/质量未验，不使用密钥或进行付费测试。
- 风险:部分服务商单次请求有字符上限(常见 4096),需要在适配器内分段;拼接 MP3 可能有轻微间隙。
