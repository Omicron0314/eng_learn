# T1.3 `/review`、`/library` 页面(含缺释义时的 AI 释义)

## 目标

提供复习界面与词卡管理界面;卡片缺释义时在首次展示时由 LLM 生成简明释义并写回卡片。

## 范围与非范围

**范围**

- `/review`:
  - 显示队列中下一张卡的正面;点击“显示答案”或按空格显示背面(释义、例句);
  - 4 个评分按钮显示 `preview` 给出的间隔,快捷键 `1`–`4`;
  - 记录从显示正面到评分的耗时作为 `durationMs`;
  - 队列为空时显示“今日已完成”,并提供回 `/today` 的链接。
- 缺释义:展示背面时若 `back_json.meaning` 为空,调用 `cardService.ensureMeaning(deps, cardId)`:用 `prompts/definition.v1.md` + `completeJson` 生成 `{ meaningZh, pos? }`,写回 `back_json`(`meaningSource="ai"`),界面标注“AI 生成”;同一卡片之后不再调用 LLM。写回卡片属于写操作,追加 `card_edit` 事件(`fields: ["meaning"]`)。
- `/library`:
  - 卡片表格:正面、释义(带来源标记)、牌组、状态、下次到期;按词搜索,按牌组、状态筛选;分页(每页 50);
  - 编辑释义与例句(`meaningSource` 改为 `user`,写 `card_edit` 事件);
  - 暂停 / 恢复(写 `card_suspend` 事件);
  - 导入表单:选择文件(CSV / .apkg)和牌组名,调用 T1.1 的 API,显示导入结果(新增、跳过、重复、错误行)。

**非范围**:词表导入为基线(T2.2 在同一表单上扩展);批量编辑;卡片删除。

## 接口

```ts
// apps/web/src/server/services/card.ts
function ensureMeaning(deps: AppDeps, cardId: string): Promise<{ meaning: string; source: "import" | "ai" | "user" }>;
function updateCardText(deps: AppDeps, input: { cardId: string; meaning?: string; example?: string }): Promise<void>;
function setSuspended(deps: AppDeps, input: { cardId: string; suspended: boolean }): Promise<void>;
```

提示词 `prompts/definition.v1.md`(新提示词,需人审),草稿:

```
System: You write concise dictionary glosses for Chinese learners of English.
Word: {word}
{example ? "Example: " + example : ""}
Give the most common meaning. Chinese meaning at most 12 characters.
Output JSON only: {"meaningZh": string, "pos": string}
```

## 验收标准

- AC1(e2e,FakeLLM):在 `/library` 导入 100 词 CSV → 进入 `/review` → 用键盘完成 20 张新卡(默认上限)→ 显示“今日已完成”。
- AC2:按 `1`–`4` 等同点击对应按钮;按钮上显示的间隔与 `preview` 一致。
- AC3:缺释义的卡片首次显示背面时 FakeLLM 被调用 1 次,界面显示“AI 生成”;刷新后再次显示同一卡片,FakeLLM 调用次数不变。
- AC4:AI 释义失败(FakeLLM 两次非法输出)时,背面显示“释义生成失败”,评分仍可进行,卡片不被修改。
- AC5:在 `/library` 编辑释义后刷新仍在,来源显示为用户编辑,`card_edit` 事件存在。
- AC6:暂停一张卡后,它不再出现在 `/review` 队列中;恢复后重新出现;每次操作各有 1 条 `card_suspend` 事件。
- AC7:搜索与筛选结果正确(集成测试覆盖查询函数)。

## 测试计划

- 集成:`cardService` 与 `CardsRepo` 的查询(AC3–AC7 的逻辑部分)。
- e2e:`review.spec.ts`(AC1、AC2)、`library.spec.ts`(AC5、AC6),使用 FakeLLM 与临时数据库。

## 依赖与风险

- 依赖 T1.2、T0.3、T1.1(导入 API)。
- **待确认**:新提示词 `definition.v1`;可能新增的 shadcn/ui 组件依赖(如 `@radix-ui/*`)按需逐个确认。
- 风险:AI 释义的质量需要人工抽查,来源标记必须始终可见。
