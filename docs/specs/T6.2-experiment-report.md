# T6.2 experiment 报告脚本

## 目标

比较文章中出现的目标词(exposed)与刻意留出的对照词(control)在之后复习中的 Again 率,验证 H3。

## 范围与非范围

**范围**

- 纯函数 `computeExperiment`(`packages/core/src/metrics/experiment.ts`):
  - 样本单位:`article_targets` 中的一行(文章,词);
  - 对每个样本,取该词卡片在文章 `created_at` 之后、`windowDays`(默认 7)天内的**第一次**复习;没有复习的样本不计入(单独报告数量);
  - 每组输出:样本数 `n`、Again 数、Again 率、无复习样本数;
  - 差值 = exposed Again 率 − control Again 率;任一组 `n=0` 时 Again 率与差值为 `null`(不输出 NaN)。
- 脚本 `tools/report/experiment.ts`,命令 `pnpm report:experiment [--db <path>] [--window <days>] [--json]`:读取数据库(默认 `DATABASE_PATH`),输出表格或 JSON;注明“样本小,仅作参考”。
- 仓储查询:`ArticlesRepo.listTargetsWithArticleTime(userId)`;复习日志用 T1.4 的 `firstReviewAfter`。
- 同一个计算函数供 T6.3 的 `/stats` 复用。

**非范围**:显著性检验;按词频或难度分层。

## 接口

```ts
type ExperimentSample = { articleId: string; lexemeId: string; role: "exposed" | "control"; articleCreatedAt: number };
type FirstReview = { rating: Rating; reviewedAt: number } | null;
type GroupResult = { n: number; again: number; againRate: number | null; noReview: number };
function computeExperiment(input: {
  samples: ExperimentSample[];
  firstReview: (s: ExperimentSample, windowEnd: number) => FirstReview;
  windowDays: number;
}): { exposed: GroupResult; control: GroupResult; diff: number | null };
```

## 验收标准

- AC1:种子数据(exposed 10 个样本中 2 个 Again,control 5 个样本中 2 个 Again)输出 exposed 0.2、control 0.4、差值 −0.2,样本数正确。
- AC2:只取第一次复习:同一样本先 Good 后 Again,按 Good 计。
- AC3:窗口边界:第 7 天内的复习计入,超过的不计入,该样本算作无复习。
- AC4:文章生成之前的复习不计入。
- AC5:无数据时两组 `n=0`、比率与差值为 `null`,脚本正常输出“暂无数据”。
- AC6:`pnpm report:experiment --json` 输出可被 `JSON.parse` 解析,字段与接口一致。

## 测试计划

- 单元:`computeExperiment`(AC1–AC5)。
- 集成:脚本在 `fixtures/seed/experiment.sql` 生成的临时库上运行(AC1、AC6)。

## 依赖与风险

- 依赖 T3.2、T1.4。
- 风险:同一词可能在多篇文章中出现,样本之间不独立;MVP 只报告,不做统计推断。
