# T5.2 播放器(变速、先听后看)

## 目标

文章页的听力播放器:变速、先听后看(正文默认折叠),听完提示难度反馈;未配置 TTS 时用浏览器朗读兜底。

## 范围与非范围

**范围**

- “生成音频”按钮调用 T5.1 的 API,生成中显示进度状态,完成后出现播放器。
- `server` 模式播放器(`<audio>`):播放 / 暂停、进度条可拖动、当前时间 / 总时长、倍速 0.75 / 0.9 / 1.0 / 1.1 / 1.25(设置 `playbackRate`)、后退 5 秒;上次使用的倍速保存在 `localStorage`。
- `browser` 模式:用 SpeechSynthesis 朗读,支持播放 / 暂停 / 停止与同样的倍速(`utterance.rate`);不支持拖动进度,界面注明“浏览器朗读”。
- 先听后看:页面有音频(或浏览器朗读可用)时,正文默认折叠,显示“显示原文”开关;开关状态不持久化(每次打开文章都先听)。
- 播放结束(`ended` 事件或朗读结束)后显示难度反馈组件(T6.1,`after="listening"`)。
- 事件:每次页面加载后第一次开始播放时写 `audio_play`(`rate`、`via`)。

**非范围**:逐句播放、A-B 循环、听写;后台播放与锁屏控制。

## 接口

```ts
// apps/web/src/components/AudioPlayer.tsx
type AudioPlayerProps = {
  articleId: string;
  source: { mode: "server"; url: string; durationS: number | null } | { mode: "browser"; text: string };
  onEnded: () => void;      // 打开难度反馈
};
```

## 验收标准

- AC1(e2e,FakeTTS):点击“生成音频”后出现播放器;播放开始后写 1 条 `audio_play` 事件;暂停再播放不重复记录。
- AC2:选择 0.75 与 1.25 时,`<audio>` 的 `playbackRate` 分别为 0.75 与 1.25;刷新后保持上次倍速。
- AC3:有音频时正文默认折叠;点击“显示原文”后可见;重新打开文章时又是折叠状态。
- AC4:FakeTTS 的短音频播放结束后,难度反馈组件出现。
- AC5:`TTS_PROVIDER=none` 时显示浏览器朗读控件(e2e 中 mock `speechSynthesis`,断言 `speak` 被调用且 `rate` 等于所选倍速)。

## 测试计划

e2e:`player.spec.ts`(AC1–AC5),使用 FakeTTS 生成的约 3 秒静音 WAV。

## 依赖与风险

- 依赖 T5.1;难度反馈组件来自 T6.1,建议在 T6.1 之后实现(否则先放占位组件,并在 T6.1 完成后补 AC4)。
- 风险:移动端浏览器的自动播放限制要求由用户手势触发播放,不做自动播放。
