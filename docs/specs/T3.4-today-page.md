# T3.4 `/today` 入口

## 目标

每天的起点页:显示今日复习任务,提供生成今日文章的入口,列出今天的文章。

## 范围与非范围

**范围**

- 今日复习:待复习数(learning + review)与新词数,来自 `reviewService.getQueue`;“开始复习”按钮跳转 `/review`;队列为空时显示“今日复习已完成”。
- 生成文章:档位选择(默认取设置)、体裁选择(默认“自动”);点击后显示进行中状态并禁用按钮;成功后跳转 `/article/[id]`。
- 错误展示:`NO_TARGETS` 显示“今天还没有可用的目标词,先去复习几张卡片”;`LLM_OUTPUT_INVALID`、`PROVIDER_ERROR` 显示可读的错误信息与“重试”按钮;`CONFIG_MISSING` 提示去 `/settings` 查看。
- 今天的文章列表:标题、体裁、coverage、是否已读完(有 `article_complete` 事件)。
- `/` 重定向到 `/today`(T0.1 已有,此处替换占位页)。

**非范围**:学习连续天数等激励功能;历史文章归档页。

## 接口

```ts
function getTodayView(deps: AppDeps): {
  queue: { learning: number; review: number; new: number };
  articles: { id: string; title: string; genre: Genre; coverage: number; completed: boolean }[];
  defaults: { tier: Tier };
};
```

## 验收标准

- AC1:页面上的待复习数与新词数等于 `getQueue` 的结果(集成 + e2e)。
- AC2(e2e,FakeLLM):点击生成后跳转到新文章页;返回 `/today` 时列表中出现该文章。
- AC3:生成过程中按钮禁用,避免重复提交。
- AC4:没有目标词时显示 `NO_TARGETS` 提示,不调用 LLM。
- AC5:FakeLLM 返回两次非法 JSON 时显示错误与“重试”按钮。
- AC6:读完的文章在列表中有“已读”标记。

## 测试计划

- 集成:`getTodayView`(AC1、AC6)。
- e2e:`today.spec.ts`(AC2–AC5)。

## 依赖与风险

- 依赖 T3.3。
- 风险:LLM 生成可能需要十几秒,先用简单的加载状态;不做流式输出。
