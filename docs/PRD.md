# 产品需求

当前基线见 [plan](plan.md)，界面以 [cijian-m3](cijian-m3.html) 为准。

## 用户与价值

面向希望用自己的词书持续学习英语的中文用户。不限定四级：设计中考研、六级、阅读生词均是自有词书的例子；英语等级支持 A2 / B1 / B2 / C1，等级说明只作参考，不声称对应正式考试认证。

词间把离散词卡带回上下文，让用户在复习之后通过短文和听力再次遇到相关词，再将阅读中的生词带回复习。用户能看见数据来源、AI 生成标识、学习负担和实际学习记录。

## 必须交付的学习体验

| 功能 | 用户能完成的事 | 主要页面 |
| --- | --- | --- |
| 今日安排 | 看队列、开始复习、进入词书、生词整理、查看近 13 周节奏 | 今日 |
| FSRS 复习 | 翻面、四档评分、预览间隔、退出／继续、缺释义时仍可评分 | 复习 |
| 文章工作区 | 选择难度／体裁、生成、查看今天和历史文章、恢复阅读 | 文章 |
| 阅读与点词 | 阅读完整文本、查语境释义／发音、标记认识／不认识／加入复习 | 文章详情 |
| 先听后看 | 合成或本机朗读、播放与变速、按能力定位、展开原文 | 文章详情 |
| 词库管理 | 导入基线／学习词书、合并、搜索／筛选、编辑／暂停、删除词书 | 词库 |
| 生词整理 | 看上下文、回来源文章、多选加入或忽略 | 生词箱 |
| 学习观察 | 新学／复习、活跃天数、覆盖率、反馈、对照实验与已学词 | 统计 |
| 个性设置 | AI 接入、学习负担、日界与时区、点词模式、实验参数、主题 | 设置 |

每个功能都包含空、加载、失败、禁用、完成状态。没有 AI 配置仍可导入、复习、编辑、阅读已有文章和播放已有音频；联网动作明确提示缺配或离线，不在后台伪造内容。

## 跨端产品范围

桌面有三栏／双栏工作区与键盘操作；窄屏有底部导航、专注复习与 bottom sheet。各平台保持同一数据语义，布局随窗口宽度变化。桌面免费朗读称为“系统朗读”，浏览器称为“浏览器朗读”，仅在实际有此能力时展示。

首轮完成桌面产品；Web/WASM 随后补齐浏览器及手机浏览器。Android / iOS 原生纳入路线图，需实际验证后排实现。各端不默认共享数据，备份恢复不等于同步。

## 首轮不包含

账号、云端同步、订阅计费、公共词书市场、外刊抓取、AI 导师、口语评分、逐句听写、完整 Anki 调度导入。它们不应挤占设计稿已有体验的交付。项目开源许可选择仍暂缓；第三方资源的许可记录照常维护。

## 体验约束

- 首页不承担文章生成配置；阅读和先听属于文章区域，返回时保持列表筛选和位置。
- 关闭释义面板不丢阅读位置；编辑未保存就切换或关闭时先处理草稿。
- 操作失败不显示成功、不吞掉用户输入；重复提交不得造成重复评分、建卡或付费合成。
- “自动建卡”在选择时和点词面板内说明后果；建卡不等于已新学，首次评分才消耗每日新词名额。
- 示例数字、词书、文章、日期和百分比不进正式空库；测试场景可以使用原创样例。
- 明暗主题、键盘焦点、触摸目标、中文输入、长文滚动与字体放大都属于完成条件。

## 验证目标

| 假设 | 观察指标 | 初始目标 |
| --- | --- | --- |
| 用户愿意持续学 | 有实际学习行为的天数、阅读完成率 | 每周 ≥5 天；完成率 ≥60% |
| 内容可读 | “刚好”比例、未知词占比 | ≥60%；中位数 ≤5% |
| 上下文有帮助 | 出现组／对照组的后续首次复习 Again 率与样本量 | 观察差值，不宣称因果 |
| 跨端行为一致 | 相同输入得到相同调度、计数与迁移结果 | 固定样例一致，已知差异有记录 |

统计口径见 [SPEC-CORE](SPEC-CORE.md)，视觉和任务追踪见 [UI-SPEC](UI-SPEC.md)。H1–H3 需 2–4 周实际使用；本次没有新的使用或质量数据。
